# <img src="icon.png" height="65"> huEVO clicker

Авто-кликер для фарма монэток

### **Фьючерс**
- отображение актуального баланса монэток и остальной инфы прямо в приложении (с расширением темперманки)
- можно выставить несколько точек, по которым курсор будет прыгать и фармить монэтки
- настраиваемый авто-клик по обычному и интервальному таймеру.
- быстрый переход в лудку по одной заметной кнопке
